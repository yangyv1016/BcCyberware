# BcCyberware v0.0.1 交付包

1. 确认服务端为 Paper 1.21.11，使用 Java 21。
2. 将 `BcCyberware-0.0.1.jar` 复制到服务端 `plugins/`。
3. 首次启动后编辑 `plugins/BcCyberware/` 中的带注释配置。
4. 如需外观，将 `BcCyberware-Example-Pack.zip` 上传到客户端可直接下载的地址，
   再按 `resources-example.yml` 的格式填入 URL。
